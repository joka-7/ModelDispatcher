# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities in modeldispatcher privately, using
GitHub's [private vulnerability reporting](https://github.com/joka-7/modeldispatcher/security/advisories/new)
(Security tab → "Report a vulnerability"), rather than opening a public issue.

You'll get an acknowledgement as soon as possible. If the report is confirmed,
a fix is prioritized and a security advisory is published once one is
available.

## Supported versions

This is a single-maintainer project with no separate LTS branches. Only the
latest commit on the default branch is supported; please make sure you can
reproduce the issue there before reporting.
